# Places Russia Bot

Telegram-гид по городам России. Первый город MVP — **Санкт-Петербург**.

## Что уже входит в первый vertical slice

- /start и главное меню города;
- каталог мест Санкт-Петербурга;
- категории: достопримечательности, необычные места, музеи, парки, с детьми, бесплатно;
- карточки мест;
- готовые маршруты;
- заглушки под экскурсии, поиск и избранное без выдуманных внешних данных;
- Docker;
- CI с Ruff и pytest;
- архитектура, рассчитанная на добавление новых городов отдельными data-модулями.

## Локальный запуск

Создайте .env из .env.example, укажите Telegram Bot Token, затем выполните:

    python -m venv .venv
    pip install -e ".[dev]"
    python -m app.main

Или:

    docker compose up --build

## Переменные окружения

    PLACES_BOT_TOKEN=123456:replace-me
    PLACES_ENVIRONMENT=development
    PLACES_CITY_SLUG=saint-petersburg

## Принцип данных

Контент, который может меняться (цены, часы работы, доступность, экскурсии, события), не должен становиться «вечной правдой» в коде. Следующий слой проекта — PostgreSQL/PostGIS + provenance и дата последней проверки источника.
